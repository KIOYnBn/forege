# 独处而不孤独——公众号笔记

- [来源](attachments/学会如何独处而不孤独——微信公众号.pdf)
- 概念区分
  - 孤独：一种消极的情绪或状态
  - 独处：客观事实， 指在物理和心理层面远离他人， 相对隔绝的状态。
- 关系
  - 很多时候， 我们置身于喧闹的人群， 心却感到被世界遗忘， 这是最锋利的孤独；
  - 反之， 当我们<span style="color:red">自愿选择与自我独处, 在有意识的聚焦之下， 我们或许不但不觉得“寂寞, 还可能因自由， 专注与沉思的空间而感到充盈</span>
- 社会性与个体性
  - 原因1：
    - 现代社会对”社交互动“的追捧和重视， 在潜意识层面将”独处“与”孤独“画上等号；
    - 独处时， 我们与嘈杂丰富的世界脱离联系， 感到无所适从， 失去<span style="color:red">被关注的价值;害怕一个人去饭馆， 电影院害怕被<u>社交审视</u>， 担心自己看起来很“可怜"</span>
  - 原因2：
    - 独处与孤独同时出现， 根源并不是"离开人群"本身， 而是我们<span style="color:red">对自我价值的不确定， 对外部评价的依赖感所导致的焦虑</span>
  - 解决：
    - <span style="color:red">重新审视个体与社会的关系， 学会并享受相对孤立的空间</span>
- 独处的意义
  - 聚焦与自省
    - <span style="color:red">把自己当作对象来观察</span>
  - 纠偏与重塑
    - <span style="color:red">对自己的行为模式， 情感需求， 价值判断等进行回溯和审视</span>
- 独处中的孤独感从何而来， 为何令我们恐惧
  - 社会本能和安全需求
    - 人类的<span style="color:red">生物本能上被设定为需要群体依托</span>， 以此获得安全感和生存资源。
    - 远古时代， 独自行动往往意味着更高的死亡风险。所以， 孤单在潜意识层面往往令我们感到不安， 恐惧以及“缺乏保护”
  - 自我评价与外界认同
    - 人在<span style="color:red">社会化</span>过程中， 会形成对外界评价的依赖。
    - 独处时， 我们无法立即获得他人的反馈， 只能自我判断， 自我评估， 这对那些自我认同度不高的人而言是一场挑战。
    - 当一个人对自我认知尚不清晰时， 这种被动的自我剥离就容易引发无所适从， 空虚感和惶恐
  - 信息与刺激的戒断
    - 很多人对电子设备， 社交平台， 工作通知等<span style="color:red">外部信息已经上瘾</span>, 当我们身处独处的场景， 要面对的是<span style="color:red">大脑即时刺激的减少</span>, 这仿佛是一种戒断反应， 大脑会把这种平静误读为<span style="color:red">被世界遗弃}</span>， 进而引发焦躁和孤独感
- 如何在独处中不感到孤独
  - 重塑价值基点：从外部到自我肯定
    - 独处时失去了<span style="color:red">外界的即时肯定与反馈</span>， 需要构建稳定而清晰的自我评价系统
    - 尝试认识自己的优点与缺点， 确立“目标-行动-反馈”的循环。
    - <span style="color:red">让自己成为自己生活的观察者和评判者}</span>
  - 发展深度兴趣
    - 产生专注或愉悦感的活动填充独处时光， 让头脑进入创造或沉浸的流动状态。
    - 此时， 孤独会让位于<span style="color:red">全神贯注的自足}</span>, 意识不到时间流逝
  - 重建与他人的连接方式
    - 独处不意味着与社会断绝，而是<span style="color:red">在与世界相处的方式上更加<u>自主， 富有节制<u></span>.
    - 每天留给自己一段封闭时段
    - <span style="color:red">节奏的切换能让独处不再与极端隔绝划等号}</span>, 而是保有一种自由自主的社交弹性
  - 训练心智的韧性与专注
    - <span style="color:red">孤独感很多时候来自心理上的脆弱或漂泊感}</span>
    - 培养内在的专注力与定力， 比如冥想， 正念呼吸等身心训练， 尝试聚焦当下
    - <span style="color:red">当一种不适或焦虑的情绪升起时， 不急于逃避， 而是凝视它的来龙去脉}</span>
    - 久而久之， 孤独的焦虑感在正念的注视下慢慢变得清晰， 不再可怕
